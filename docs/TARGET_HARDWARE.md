# Эталонное оборудование для замеров

Все измерения производительности в отчётах привязаны к конфигурациям из этого файла. Расчётные бюджеты из `ARCHITECTURE.md` (раздел 10.1) считаются подтверждёнными только после замера на соответствующем эталоне.

## Эталон A — «встроенная графика» (зафиксирован 2026-11-15)

Единственная машина, на которой сейчас возможны реальные замеры.

| Параметр | Значение |
|---|---|
| Процессор | Intel Core i5-1235U (12-е поколение, 2 производительных + 8 энергоэффективных ядер, 12 потоков) |
| Графика | Intel Iris Xe (встроенная), драйвер 31.0.101.4032 |
| Память | 8 ГБ (доступно системе 7,7 ГБ), общая с графикой |
| Экран | 1920×1080 |
| ОС | Windows 11 Home 10.0.26200 |
| Браузер тестов | Microsoft Edge (Chromium), системная установка |
| Node.js | 24.22.1 |

Условия замеров: окно 1280×720 в безголовом режиме, если не указано иное; частота кадров ограничена вертикальной синхронизацией (60 Гц), поэтому «60 к/с» означает «не ниже 60».

## Эталон B — «дискретная графика» (не зафиксирован)

В архитектуре целевой машиной назван ПК с видеокартой уровня GTX 1650. Такой машины для замеров нет. До её появления:

- все результаты относятся только к эталону A;
- эталон A слабее заявленной цели, поэтому выполненный на нём бюджет с высокой вероятностью выполнится и на B, но обратное неверно;
- пресет «средние настройки» остаётся неподтверждённым.

**Требуется решение заказчика:** считать ли эталон A основной целевой конфигурацией проекта.

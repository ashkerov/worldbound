## 1. Согласованность уровней симуляции

Прототип `prototypes/lod`: трава → кролики → лисы. Мир 12 × 12 чанков (1,5 × 1,5 км), **16 seed, 1000 игровых суток** (50 лет), первые 200 суток отброшены. Данные: `measurements/phase1c-lod.json`.

Эталон — пространственная почасовая модель на весь мир: 2547 ± 28 кроликов, 362 ± 9 лис. Второй независимый набор из 16 seed отличается на 0 %, +3 % и −1 % — это уровень шума.

### 1.1. Насколько упрощённый «дальний уровень» повторяет эталон

| Дальний уровень | Кролики | Лисы | Трава |
|---|---|---|---|
| Когорты: счётчики по стадиям и средняя энергия | +66 % | −83 % | −1 % |
| Особи, суточный шаг «в среднем по чанку» | +9 % | −46 % | +34 % |
| Особи с положением, суточный шаг по ячейкам | +32 % | +27 % | −48 % |

Все отклонения превышают шум в десятки раз (от 7 до 57 стандартных ошибок). Параметры дальних уровней при этом откалиброваны по эталону, то есть это лучший достижимый для них результат.

### 1.2. Неподвижная камера, облёт мира и отсутствие наблюдения

Сравнение с прогоном без наблюдателя. «Область» — центральные 3 × 3 чанка.

| Дальний уровень | Наблюдение | Мир: кролики / лисы | Область: кролики / лисы |
|---|---|---|---|
| Когорты | Неподвижно, зона 3 × 3 | −7 % / +205 % | −14 % / +321 % |
| Когорты | Неподвижно, зона 5 × 5 | −17 % / +373 % | −27 % / +757 % |
| Когорты | Облёт мира | −5 % / +169 % | −7 % / +178 % |
| Усреднение по чанку | Неподвижно, зона 3 × 3 | −3 % / 0 % | +6 % / +5 % |
| Усреднение по чанку | Неподвижно, зона 5 × 5 | −6 % / +5 % | −7 % / +57 % |
| Усреднение по чанку | Облёт мира | −4 % / +7 % | −6 % / +6 % |
| Суточный шаг по ячейкам | Неподвижно, зона 3 × 3 | +1 % / +1 % | −22 % / −37 % |
| Суточный шаг по ячейкам | Неподвижно, зона 5 × 5 | −2 % / +1 % | −18 % / −1 % |
| Суточный шаг по ячейкам | Облёт мира | +1 % / +2 % | +2 % / +3 % |
| **Единая модель** | Любое | 0 / 0 | 0 / 0 |

Для единой модели ноль — не результат измерения с допуском, а свойство: камера не участвует в расчёте, и тест подтверждает побитное совпадение состояния мира при трёх разных режимах наблюдения.

### 1.3. Переходы «когорта ↔ особи»

Проверены тестами (`tests/sim/lod.test.ts`, 9 из 9): численность по чанкам и суммарная энергия сохраняются при свёртывании и воплощении; многократное переключение без хода времени не меняет мир; книга учёта сходится каждые сутки во всех режимах. Сами переходы работают корректно — проблема когорт не в переходах, а в том, что усреднённая модель живёт по другой динамике.

### 1.4. Вывод

Когорты, заложенные в архитектуру 1.0, обязательный критерий «нет эффекта наблюдателя» не проходят. Принята **единая модель**: звери и птицы всегда индивиды, один расчёт блоками около игрового часа для всего мира, у камеры добавляется только показ. Решение внесено в `ARCHITECTURE.md`, раздел 9.0.

## 2. Расширенная пищевая сеть

Прототип `prototypes/web` на единой модели. Два продуцента (трава, кустарник), два травоядных (кролик, олень), два хищника (лиса — всеядная, волк — охотится на оленей и кроликов). Четыре сезона с градиентом север — юг, останки возвращают вещества в почву. Мир 1 × 3 км, **16 seed, 1000 суток**. Данные: `measurements/phase1-foodweb.json`. Тесты: `tests/sim/web.test.ts`, 8 из 8.

Правила соблюдаются без исключений за все прогоны: ни одного выводка вне сезона вида, у неполовозрелой особи или при энергии ниже порога.

Смерть от старости наступает не раньше 80 % видового срока жизни. Каждая смерть записана с причиной и сезоном; сумма по причинам равна убыли.

### 2.4. Миграция

| Вид | Сдвиг зимой относительно лета | В скольких мирах к югу |
|---|---|---|
| Олень (кочующий) | 341 м к югу | 16 из 16 |
| Кролик (оседлый) | 10 м к северу | 2 из 16 |
| Лиса (оседлая) | 2 м | 10 из 16 |
| Волк (кочующий за оленями) | 0 м | 9 из 16 |

Без сезонов сдвига нет (контрольный тест).

Две оговорки:

- Миграция оленей получена **врождённым сезонным стремлением**, заложенным в модель. Первая версия, где олень искал лучший корм в ста метрах от себя, миграции не дала: сдвиг был около нуля, потому что градиент условий слишком плавный.
- Волки за оленями не пошли: их правило следования оказалось слишком слабым.

### 2.5. Трофические каскады

8 seed × 600 суток, сравнение с тем же миром без одного вида.

| Изменение | Олени | Кустарник | Кролики | Трава |
|---|---|---|---|---|
| Убрали волков | +41 % (8 из 8) | −23 % (8 из 8) | −18 % (7 из 8) | −25 % (7 из 8) |
| Убрали лис | −32 % (8 из 8) | +12 % (8 из 8) | +29 % (8 из 8) | −3 % (5 из 8) |

Это пример из ТЗ («исчезли хищники → больше травоядных → меньше растительности»), полученный расчётом. Возникли и непредусмотренные следствия: без волков расплодившиеся олени объедают траву и вытесняют кроликов; без лис расплодившиеся кролики вытесняют оленей, и кустарник восстанавливается. Эффект отсутствия лис на траве не выражен.

### 2.6. Что потребовалось для устойчивости

Первые версии сети разрушались за 5–10 игровых лет. Последовательно понадобились:

1. **Укрытия для добычи**: кролик не виден в густой траве, олень — в густом кустарнике. Когда добычи мало, растительность густая и добыча защищена.
2. **Территориальность хищников**: предел числа особей на участке, при котором возможен выводок.
3. **Раздел кормовой базы**: олень сначала ест кустарник, кролик — только траву.

Без любого из трёх один из видов вымирал. Отдельно: всеядность лисы без ограничения территорий привела к истреблению кроликов — подкормленный хищник не голодает и не даёт добыче восстановиться.

В мире вдвое меньше (6 × 16 чанков) лисы вымерли в 1 из 3 прогонов: **малые популяции хищников неустойчивы**.

### 2.7. Стоимость

51 мс на игровые сутки при 2,7 тыс. особей четырёх видов (Node).

### 4.5. Длинные кадры WebGL 2 — расследование

В замерах без окна на WebGL 2 встречались кадры по 0,3–3 секунды. Проверены три режима на среднем пресете (`measurements/phase1-headed-webgl2-control-*.json`):

| Режим | Синхронизация кадров | Худший кадр | Кадров дольше 100 мс |
|---|---|---|---|
| Видимое окно | Включена | 60 мс | 0 из 7646 |
| Без окна | Включена | 33 мс | 0 из 4621 |
| Видимое окно | **Отключена** | 0,75–1,2 с | 105 из 5538 |

**Причина — флаги стенда**, отключающие вертикальную синхронизацию и ограничение частоты кадров (`--disable-gpu-vsync`, `--disable-frame-rate-limit`), а не отсутствие окна и не код сцены. Без ограничения страница отправляет кадры быстрее, чем видеокарта успевает их выполнить; очередь растёт и периодически блокирует поток на сотни миллисекунд. На WebGPU этого не происходит ни в одном режиме.

В обычном браузере синхронизация включена всегда, поэтому игрок с этими зависаниями не столкнётся. Следствие для проекта: частоту кадров на WebGL 2 нельзя оценивать по замерам без синхронизации — средние значения там завышены.

### 4.6. Границы проекта и ассеты

- `npm run check:boundaries` — 9 из 9 запрещённых импортов отклоняются; прототипы лежат в `prototypes/` и в `src/` не подключаются.
- `npm run check:assets` — в манифесте две записи (Stag и Farmer, Quaternius, CC0 1.0), обе проверены по страницам источника; файлы на месте. Удалённая модель лисы в манифесте не числится.

## 6. Ограничения и что не проверено

- Все замеры — на одной машине со встроенной графикой. Высокий пресет на дискретной видеокарте не проверялся.
- Проверен только Edge (Chromium). Firefox и Safari не проверялись.
- Разброс замеров кадров — до ±20 %: процессор на 15 Вт снижает частоту под длительной нагрузкой.
- Замеры кадров без окна (раздел 4.2) сняты до ослабления tilt-shift и после него не повторялись; в видимом окне замеры сделаны уже с новым tilt-shift.
- Прогон на устойчивость длился 2 минуты на путь, а не часы.
- Модели экосистемы — прототипы из трёх и шести звеньев. Растения как система, вода, погода, опыление и пожары не моделировались.
- Единая модель проверена как расчёт; слой воплощения (существо разыгрывает решение блока у камеры) не делался.
- Совместный прогон шёл на небольшой сцене диорамы, а не на мире 4 × 4 км.
- Модели существ в прототипе 1A — временные.

## 7. Рекомендации

1. **Утвердить единую модель симуляции.** Это главное архитектурное следствие фазы 1; сейчас оно внесено в документы как предложение исполнителя.
2. **Перейти к фазе 2 «Мир и среда»**: генерация мира из seed с естественными границами, рельеф и вода в стиле прототипа, время и погода, первый формат сохранений.
3. **Держать бюджет Iris Xe с первого дня**: до 1 млн треугольников за кадр, одна карта теней с редким обновлением, отрисовка в 0,75 разрешения на среднем пресете. Мерить в видимом окне.
4. **Заложить стабилизаторы экосистемы в проект видов**: укрытия, территориальность, раздел кормовой базы — как данные вида, а не как частные случаи.
5. **Размер мира и колонизация извне** должны учитывать минимальную жизнеспособную популяцию хищников.

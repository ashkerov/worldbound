## 1C. Согласованность уровней

Модель «трава → кролики → лисы», мир 12×12 чанков, 400 суток (20 игровых лет), 6 seed-ов на режим. Это быстрый прогон; полный (16 seed-ов, 1000 суток) не запускался.

Эталон — пространственная почасовая модель на весь мир (S0): 2458 ± 52 кроликов, 276 ± 16 лис. Шум между двумя наборами seed-ов: +3 % / +1 %.

| Дальний уровень | Кролики к эталону | Лисы к эталону | Эффект наблюдателя |
|---|---|---|---|
| Когорты (счётчики + средняя энергия) | +79 % | −71 % | Грубый: лис в мире +95…+235 %, в наблюдаемой области до +529 % |
| Особи, суточный шаг «в среднем по чанку» | +8 % | −28 % | Умеренный: мир −5 % / +2…7 %; в области 5×5 лис +58 % |
| Особи с положением, суточный шаг по ячейкам | +38 % | +66 % | В мире около нуля; в области 3×3 кроликов −24 %, лис −40 % |
| Единая модель (тот же почасовой расчёт везде, камера влияет только на показ) | 0 | 0 | Нет по построению: хеш состояния побитно одинаков при любой зоне наблюдателя (тест) |

**Вывод.** Ни одно упрощение дальнего уровня не уложилось в шум; когорты, заложенные в `ARCHITECTURE.md` (раздел 9), критерий «нет эффекта наблюдателя» не проходят. При этом полная модель достаточно дешева, чтобы считать весь мир одинаково (см. 1D). Предлагаемое изменение архитектуры: звери и птицы — всегда индивиды; один авторитетный расчёт блоками около игрового часа для всего мира; вблизи камеры добавляется только «воплощение» (пути, анимация). Поля остаются для насекомых, разлагателей и травы. Раздел 9 архитектуры под это **ещё не переписан**.

Оговорка: вывод получен на одной упрощённой модели из трёх видов; реальная фауна будет сложнее.

| Замер | Node | Воркер браузера |

## 1B. Нагрузка рендера (Intel Iris Xe)

Сцена: мир 4096 м, 300 тыс. деревьев с тремя LOD по чанкам, 60 тыс. пучков травы, 3000 существ с анимацией из текстуры, тень 2048².

| Вариант | Обзор сверху | Средняя высота | У земли |
|---|---|---|---|
| WebGPU 1080p, полная | 20 к/с | 17 к/с | 28 к/с |
| WebGL 2 1080p, полная | 23 к/с | 18 к/с | 25 к/с |
| WebGPU 720p, полная | 35 к/с | 25 к/с | 22 к/с |
| WebGL 2 720p, полная | 37 к/с | 26 к/с | 25 к/с |
| WebGPU 1080p, без теней | 48 к/с | 30 к/с | 31 к/с |
| WebGPU 1080p, «низкие» (150 тыс. деревьев, 1000 существ, 20 тыс. травы, без теней) | 56 к/с | 54 к/с | 57 к/с |

- Полная сцена — 3,2–5,9 млн треугольников за кадр; встроенная графика это не тянет. «Низкие» — 0,7–1,2 млн, и это подтверждает бюджет ≤ 1,5 млн.
- Тени стоят примерно половину кадра: в карту теней попадает слишком много геометрии.
- Рывки: 1 % худших кадров 65–180 мс на WebGPU и 180–310 мс на WebGL 2. Причина — создание геометрии чанков на главном потоке при смене LOD; в игре это должно уйти в рабочие воркеры.
- Анимация из текстуры для 3000 существ работает на обоих путях; 340–660 вызовов отрисовки проблемой не стали.
- Память JS — 47–70 МБ.

Картинка стенда — техническая (примитивы), к визуальному стилю отношения не имеет.

# Авторы и лицензии ассетов

Машинно-читаемый источник — [`manifest.json`](manifest.json). Этот файл — его человекочитаемое отражение.

## Правила (утверждены 2026-11-15)

- Разрешены только **CC0 1.0** и **CC-BY 4.0**, а также собственные работы проекта. Предпочтение — CC0.
- Для CC-BY обязательно: автор, ссылка на первоисточник, конкретная лицензия, перечень внесённых изменений.
- CC-BY-NC, CC-BY-ND, CC-BY-SA и материалы с неясными условиями — только после отдельного согласования.
- Проект может стать коммерческим: лицензия каждого ассета должна это допускать.
- Запись в манифест делается в момент добавления ассета; `npm run check:assets` входит в общую проверку.

## Собственные работы проекта

Всё остальное в прототипе 1A создано кодом проекта и сторонних материалов не содержит: рельеф, вода и водопад, три вида деревьев, кусты, трава, цветы, камыш, кувшинки, грибы, камни, дом, забор, мост, фонарь, небо, облака, текстуры листвы и дыма (рисуются на canvas при запуске).

### Рендер растительности Unity (ветка `experiment/unity-flora-renderer`)

Собственная работа проекта, сторонних материалов нет: процедурные модели ели, сосны, берёзы, дуба, липы, ольхи, лещины, шиповника, ивы и можжевельника (возрастные варианты и три уровня детализации), травы (мятлик, ковыль, осока, клевер, луговые цветы, иван-чай, черника, мох), атлас листвы и шум ветра — рисуются кодом при запуске (`Runtime/WorldView/Flora/Gfx/FloraTextures.cs`), атлас импосторов запекается из этих моделей; шейдеры URP — `Runtime/WorldView/Flora/Shaders/`. Небо графического стенда — встроенный шейдер Unity `Skybox/Procedural`.

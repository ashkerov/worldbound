# WORLDBOUND

Симулятор живого мира: игрок создаёт условия, а природа и цивилизации развиваются сами.

- **Контекст проекта для новой сессии — [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)**
- Архитектура — [ARCHITECTURE.md](ARCHITECTURE.md)
- План разработки — [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)
- Отчёты по фазам — [docs/](docs/)
- Исходное ТЗ и визуальные референсы хранятся локально в `reference/` и в репозиторий не входят

**Состояние:** фазы 0 и 1 завершены; **фаза 2 «Мир и среда»** выполнена и ждёт оценки заказчика — [docs/PHASE2_REPORT.md](docs/PHASE2_REPORT.md). В игре есть процедурный мир (рельеф, реки, озёра, море, климат, почвы, провинции), время, сезоны, погода, камеры и сохранения. Растений и животных пока нет (фазы 3–4).

## Визуальный прототип

```bash
npm run diorama
```

Открывает диораму 150 × 150 м — визуальную цель игры (`prototypes/diorama/`). Отчёт и скриншоты — в [docs/PHASE1A_REPORT.md](docs/PHASE1A_REPORT.md).

## Требования

- Node.js 22 или новее (проверено на 24.22).
- Браузер на Chromium (Edge или Chrome) — для игры и сквозных тестов.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть <http://127.0.0.1:5173>: главное меню → «Новый мир» (seed, размер, климат, длина сезона) или открыть сохранённый.

Параметры адресной строки:

| Параметр | Значение |
|---|---|
| `renderer=webgl2` | Принудительно WebGL 2 (по умолчанию — WebGPU, при недоступности автоматически WebGL 2) |
| `quality=low\|medium\|high` | Пресет графики (по умолчанию — сохранённый выбор или средний) |
| `autostart=1&seed=…&size=S\|M&season=3\|5\|8&climate=cold\|temperate\|warm` | Сразу создать мир без меню (проверки, стенды) |
| `debug=1` | Открыть панель отладки (также F3) |
| `agents=<N>` | Тестовые агенты фазы 0 для нагрузки (до 16384) |

Управление:

| Действие | Стратегическая камера | Свободная камера |
|---|---|---|
| Левая кнопка, перетаскивание | сдвиг | вращение |
| Правая кнопка, перетаскивание | вращение | сдвиг |
| Колесо, R / F | масштаб (у земли взгляд становится положе) | дистанция |
| W A S D, стрелки / Q E | движение / поворот | движение / поворот |
| Щелчок | карточка ячейки | карточка ячейки |

Tab — смена камеры, H — скрыть интерфейс, пробел — пауза, F3 — отладка. Щелчок по мини-карте — перелёт.

## Проверки

| Команда | Что делает |
|---|---|
| `npm run verify` | Типы, линтер, границы модулей, манифест ассетов, модульные тесты |
| `npm run test` | Модульные тесты и headless-тесты симуляции (Vitest) |
| `npm run build` | Проверка типов и производственная сборка в `dist/` |
| `npm run test:e2e` | Сквозные тесты в системном браузере на WebGPU и WebGL 2 (нужна сборка) |
| `npm run headless -- --size M --ticks 7200` | Генерация мира и прогон симуляции в Node без браузера |
| `npm run worldgen -- --seed 42 --size M` | Предпросмотр генератора: время этапов и PNG-карты (рельеф, осадки, почвы, провинции) |
| `npm run check:boundaries` | Доказывает, что запрещённые импорты отклоняются |
| `npm run bench` | Стенды фазы 1 без окна (нужна сборка `npm run build:bench`, включающая страницы прототипов) |
| `npm run test:headed` | Проверки в видимом окне: облёт мира M (`world-flyover`), сезоны (`seasons`), диорама фазы 1 |

Сквозные тесты по умолчанию идут в Edge. Другой браузер: `WB_BROWSER_CHANNEL=chrome`. Показать окно: `WB_HEADED=1`.

Формат сохранений — [docs/SAVE_FORMAT.md](docs/SAVE_FORMAT.md). Миры хранятся в OPFS браузера на этом компьютере.

## Структура

```
src/shared     ГПСЧ, идентификаторы, время, протокол — без зависимостей
src/sim        ядро симуляции: без DOM, three и React; работает и в воркере, и в Node
src/worker     воркер симуляции и его клиент на главном потоке
src/render     three.js (WebGPU с откатом на WebGL 2); читает только снимки протокола
src/ui         React-интерфейс; получает данные из хранилища, отправляет команды
src/platform   хранилище (OPFS, память)
src/app        запуск и связывание слоёв
tools          headless-прогон, проверки границ и ассетов, стенды прототипов
tests          модульные, симуляционные и сквозные тесты
content        каталоги данных (почвы — с фазы 2; растения, животные — с фаз 3–4)
assets         исходные ассеты, CREDITS.md и манифест лицензий
```

Границы модулей проверяются автоматически: ядро симуляции компилируется без библиотеки DOM, а линтер запрещает импорты между слоями.

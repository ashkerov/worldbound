## 1. Концепция и философия

WORLDBOUND — одиночная песочница-симулятор живого мира для ПК (первоначально в браузере). Жанры: God Simulator, Sandbox, Life / Ecosystem / Civilization Simulation.

Игрок — создатель и наблюдатель. Он формирует ландшафт, климат и условия; растения, животные, а позже разумные существа и цивилизации развиваются сами.

**Главная философия [Утверждено]:** игрок создаёт мир, но не пишет его историю — история возникает из взаимодействия систем.

Восемь принципов, которые нельзя нарушать [Утверждено, ТЗ §31]:

1. Каждый элемент имеет смысл и входит в общую систему.
2. Все основные элементы взаимосвязаны: природа ↔ животные ↔ цивилизации ↔ среда.
3. Мир автономен: существа сами принимают решения.
4. Свобода игрока: нет сюжета, победы и поражения.
5. Красота мира; никакого пиксель-арта и примитивного low-poly.
6. Реальные механики: если функция есть в интерфейсе, она работает. Никаких заглушек.
7. Производительность при большом числе объектов.
8. Бесплатность: без платных API, подписок и обязательных серверов.

Полное ТЗ (32 раздела) — у заказчика локально в `reference/требования.txt`; в репозиторий не входит.

## 3. Архитектура и стек

Подробно — `ARCHITECTURE.md` (версия 1.1).

| Слой | Решение | Статус |
|---|---|---|
| Платформа | Браузер (ПК), статическое приложение без сервера | Утверждено |
| Язык | TypeScript (strict) | Утверждено |
| Рендер | three.js `WebGPURenderer` + TSL, автоматический откат на WebGL 2; без react-three-fiber | Утверждено |
| Симуляция | Собственное ядро без DOM в Web Worker; типизированные массивы; без ECS-библиотеки | Утверждено |
| Интерфейс | React + Zustand поверх канваса | Утверждено |
| Хранилище | OPFS в воркере, абстракция `StoragePort` | Утверждено; реализован только самотест |
| Сборка и проверки | Vite, Vitest, Playwright (системный Edge), ESLint | Утверждено |

Зафиксированные версии: three 0.187.0, React 19.3.1, Zustand 5.1.0, Vite 8.3.8, TypeScript 6.0.3, Vitest 5.1.0, Playwright 1.65.1, ESLint 10.15.0.

Структура:

```
src/shared     ГПСЧ, идентификаторы, время, протокол
src/sim        ядро симуляции (без DOM, three, React)
src/worker     воркер симуляции и клиент
src/render     three.js; читает только снимки протокола
src/ui         React-интерфейс
src/platform   хранилище
src/app        связывание слоёв
prototypes/    одноразовые прототипы фазы 1: lod, web, bench, diorama
tests/         unit, sim (Vitest); e2e, bench, headed (Playwright)
tools/         headless-прогон, проверки границ и ассетов
docs/          отчёты, замеры, скриншоты
assets/        манифест лицензий и CREDITS.md
```

Границы модулей проверяются автоматически (`npm run check:boundaries`): ядро компилируется без библиотеки DOM, линтер запрещает импорты между слоями. Прототипы лежат вне `src/` и границы не нарушают.

## 4. Ключевые архитектурные решения и их причины

| Решение | Причина | Статус |
|---|---|---|
| Симуляция — единственный авторитет; рендер, интерфейс и звук только читают снимки и шлют команды | Независимость от кадра, тестируемость в Node, отсутствие «декоративных» величин | Утверждено |
| Каждая транзакция (смерть, рождение, расход) несёт код причины | Аналитика «почему» строится из данных, а не сочиняется | Утверждено |
| Контент — каталоги данных, а не код | Расширение видов, биомов, зданий без переписывания | Утверждено |
| Счётчиковый ГПСЧ: значение зависит только от (seed, система, сущность, такт) | Случайность не зависит от порядка обхода и положения камеры | Утверждено; реализовано |
| **Единая модель симуляции вместо когорт**: звери и птицы всегда индивиды; один расчёт блоками около игрового часа для всего мира; у камеры — только «воплощение» | Измерено: когорты и два других упрощения расходятся с эталоном на десятки процентов и дают эффект наблюдателя; единая модель его не имеет и достаточно дёшева (раздел 5) | **Утверждено** заказчиком 2026-11-16 (решение №21); когорты как основной способ симуляции не использовать |
| Камера не влияет на состояние мира и поведение существ | Требование заказчика; следствие единой модели | **Утверждено** 2026-11-16 (решение №22) |
| Трава, насекомые, разлагатели — поля по ячейкам 8 м; деревья — компактные постоянные индивиды | Самая дешёвая форма, в которой сущность остаётся настоящей | Утверждено (в составе архитектуры 1.0) |
| Сельхозкультуры — те же растения; охота и рубка работают с теми же хранилищами | Влияние цивилизации на природу получается без отдельного кода | Утверждено (в составе архитектуры 1.0) |
| Естественные границы мира вместо среза | Решение заказчика №11 | Утверждено |
| Модель существа подключается через манифест представления | Решение заказчика №13 | Утверждено как требование; **не реализовано** |
| Шкала времени: такт 100 мс = 12 игровых секунд, сутки 12 мин на ×1, год 20 суток | Существа должны двигаться с правдоподобной видимой скоростью | **Предварительно**; заказчик явно не подтверждал, плейтеста не было |

История отменённых решений сохранена в `ARCHITECTURE.md` (журнал изменений и раздел 9).

## 5. Требования к симуляции и что о них известно

Требования [Утверждено, ТЗ §6–9, §18]: растения растут, конкурируют и расселяются; животные ищут пищу и воду, размножаются, стареют, мигрируют, вымирают; работают пищевые цепи, опыление, перенос семян, разложение и круговорот веществ; события возникают из процессов, а не генерируются для развлечения.

### 5.1. Согласованность уровней [Эксперимент]

Прототип `prototypes/lod`: трава → кролики → лисы, мир 12×12 чанков, **16 seed, 1000 игровых суток**. Данные: `docs/measurements/phase1c-lod.json`.

Эталон — пространственная почасовая модель: 2547 ± 28 кроликов, 362 ± 9 лис. Шум между двумя наборами seed-ов: 0–3 %.

| Дальний уровень | Кролики | Лисы | Трава | Эффект наблюдателя |
|---|---|---|---|---|
| Когорты | +66 % | −83 % | −1 % | Лис в мире +169…+373 %, в наблюдаемой области до +757 % |
| Особи, шаг «в среднем по чанку» | +9 % | −46 % | +34 % | В области 5×5 лис +57 % |
| Особи, суточный шаг по ячейкам | +32 % | +27 % | −48 % | В области 3×3 кроликов −22 %, лис −37 % |
| Единая модель | 0 | 0 | 0 | Нет: хеш состояния одинаков при любой зоне наблюдения (тест) |

Сравнивались неподвижная камера (зоны 3×3 и 5×5), обход мира и отсутствие наблюдения.

### 5.2. Расширенная пищевая сеть [Эксперимент]

Прототип `prototypes/web`: трава и кустарник → кролик и олень → лиса (всеядная) и волк; сезоны с градиентом север — юг; мир 1 × 3 км, **16 seed, 1000 суток (50 игровых лет)**. Данные: `docs/measurements/phase1-foodweb.json`.

- **Устойчивость:** все четыре вида животных выжили в 16 из 16 миров.
- **Размножение:** кролики — весна 42 %, лето 35 %, осень 23 %, зима 0 %; олени и волки — только весной; лисы — весной и летом. Ни одного выводка у неполовозрелых и ниже порога энергии.
- **Смертность:** у кроликов 45 % — хищники, 32 % — голод; у оленей 69 % — хищники; старость не раньше 80 % срока жизни.
- **Миграция:** олени зимой в среднем на 341 м южнее, чем летом (в 16 из 16 миров); кролики и лисы не смещаются; волки за оленями не пошли.
- **Каскады:** см. `docs/PHASE1_REPORT.md`.
- **Стоимость:** 51 мс на игровые сутки при 2,7 тыс. особей.

Оговорки:

- Миграция получена **врождённым сезонным стремлением**, заложенным в модель. Из одного лишь градиента условий она не возникла — градиент слишком плавный.
- В мире вдвое меньше (6×16 чанков) лисы вымерли в 1 из 3 миров: малые популяции хищников неустойчивы.
- Устойчивость потребовала стабилизаторов: укрытий для добычи (трава для кролика, кустарник для оленя) и территориальности хищников. Без них сеть разрушалась за 5–10 лет.
- Модель — прототип из шести звеньев; полная фауна игры будет сложнее.

### 5.3. Производительность симуляции [Эксперимент]

Данные: `docs/measurements/phase1d-node.json`, `phase1d-browser.json`.

- Такт 5000 агентов (восприятие каждый такт, выбор по полезности): 2,2 мс в воркере браузера, p95 3,5 мс.
- Суточный проход полей 512² с четырьмя слотами видов: 22 мс.
- Единая модель, 18,4 тыс. кроликов и 2,3 тыс. лис в мире 4 × 4 км: 0,26–0,34 с на игровые сутки.

### 5.4. Не проверено

- Растения как система (рост, конкуренция, расселение, сукцессия) — только трава и кустарник как поля.
- Опыление, перенос семян, вода, погода, пожары — не моделировались.
- Поведение воплощённых агентов (пути, анимация по решениям блока) — не делалось.
- Догоняние после закрытия игры, сохранения мира — не делались.

## 6. Требования к графике

Стиль **Cozy Stylized 3D** [Утверждено]: детализированная стилизованная графика, натуральная палитра, мягкий свет, объёмные объекты, плавные анимации, уютная архитектура. Не фотореализм, не пиксели, не примитивный low-poly, не геометрические животные.

Визуальная цель v0.1 — прототип 1A (`prototypes/diorama`, отчёт `docs/PHASE1A_REPORT.md`):

- Процедурные деревья трёх видов с листовыми карточками, трава пучками, цветы, кусты, камыш, камни.
- Дом из отдельных камней, досок и дранок; окна и фонарь светятся ночью; дым.
- Река, водопад, заводь, мост.
- Цикл дня и ночи, мягкие тени, дымка, слабый tilt-shift в стратегическом режиме.
- Две камеры: стратегическая и свободная; слежение за существом.
- Три пресета качества.

Известные слабые места [Эксперимент — по скриншотам]: существа проще окружения; скала плоская; у воды нет отражений и прозрачности; нет затенения в складках; сезонов, дождя и снега нет.

Направления улучшения — решение №9 в разделе 2.

## 8. Целевое оборудование и производительность

**Эталон A** (единственная машина для замеров, `docs/TARGET_HARDWARE.md`): Intel Core i5-1235U, Intel Iris Xe, 8 ГБ ОЗУ, Windows 11, Edge (Chromium), экран 1920 × 1080.

Статус эталона: заказчик поручил тестировать на нём и принял показатели для Iris Xe (решение №15) — **де-факто основная цель v0.1**. Машины с дискретной видеокартой для замеров нет: высокий пресет на целевом для него оборудовании **не проверен**.

Диорама, 1920 × 1080, без видимого окна, вертикальная синхронизация отключена [Эксперимент, `docs/measurements/phase1a-fps-*.json`]:

| Пресет | Отрисовка | WebGPU | WebGL 2 |
|---|---|---|---|
| Низкое | 1056 × 594 | 54–96 к/с | 101–114 к/с |
| Среднее | 1440 × 810 | 35–46 к/с | 44–60 к/с |
| Высокое | 1920 × 1080 | 11–20 к/с | 19–28 к/с |

Эти замеры сделаны до ослабления tilt-shift; после него не повторялись.

Диорама в **обычном видимом окне** Edge, область 1600 × 900, средний пресет (отрисовка 1200 × 675), синхронизация включена [Эксперимент, `docs/measurements/phase1-headed-*.json`]:

| Режим | WebGPU | WebGL 2 |
|---|---|---|
| Только рендер | 41–57 к/с, худший кадр 45 мс | 55–60 к/с, худший кадр 60 мс |
| Рендер + воркер симуляции (5000 агентов на ×8) | 39–60 к/с | 47–60 к/с |
| Кадров дольше 100 мс | 0 | 0 |
| Тактов симуляции получено / требуется | 80 / 80 | 80 / 80 |

Прогон 2 минуты на путь: ошибок, потери контекста и роста памяти нет.

**Длинные кадры WebGL 2 (0,3–3 с) [Эксперимент]:** причина — флаги стенда, отключающие вертикальную синхронизацию. С синхронизацией их нет ни в окне, ни без окна; без синхронизации в окне они появляются (105 из 5538 кадров, до 1,2 с). В обычном браузере не возникают.

Стенд масштаба мира 4 × 4 км (300 тыс. деревьев, 3000 существ, трава, тени) [Эксперимент, `phase1b-*.json`]: 17–28 к/с в 1080p; без теней 30–48; облегчённая сцена 54–57. Вывод: на Iris Xe комфортно 0,5–1,0 млн треугольников.

Все замеры имеют разброс до ±20 %: процессор на 15 Вт снижает частоту под длительной нагрузкой.

## 10. Известные проблемы и риски

| № | Проблема или риск | Статус |
|---|---|---|
| 1 | Качество моделей существ ниже окружения; лучших бесплатных риггованных моделей без регистрации не найдено | Открыто; модели временные (решение №12) |
| 2 | Единая модель симуляции проверена на шести звеньях; с полной фауной год расчёта может не уложиться в цель догоняния | Риск |
| 3 | Малые популяции хищников неустойчивы в небольших мирах | Подтверждено экспериментом; нужно учесть в размерах мира и колонизации извне |
| 4 | Баланс экосистемы держится на стабилизаторах (укрытия, территории); без них сеть разрушается | Подтверждено экспериментом |
| 5 | Миграция не возникает из плавного градиента условий — нужен врождённый сезонный механизм | Подтверждено экспериментом |
| 6 | Длинные кадры WebGL 2 | **Закрыто**: артефакт стенда с отключённой синхронизацией кадров (раздел 8). Замерам WebGL 2 без синхронизации доверять нельзя |
| 7 | Высокий пресет не играбелен на Iris Xe (11–28 к/с) и не проверен на дискретной видеокарте | Открыто |
| 8 | Проверен только Edge (Chromium); Firefox и Safari не проверялись | Открыто |
| 9 | Шкала времени не проходила плейтест | Открыто |
| 10 | Формата сохранений нет; его эволюция — будущий риск | Не начато |
| 11 | API `WebGPURenderer` и TSL ещё меняется | Версия three зафиксирована |
| 12 | Объём проекта очень велик | Вертикальные срезы; правило «нет интерфейса без механики» |
| 13 | Прототипы собираются вместе с игрой (`vite.config.ts`) | Убрать из сборки игры при переходе к фазе 2 |
